# 치지직 멀티뷰 (Chzzk MultiView)

내가 고른 치지직 라이브 방송 여러 개를 한 화면에 띄워 두고, 방송마다 소리를 따로 조절하고, 원하는 방송의 채팅창만 켜고 끌 수 있는 안드로이드 앱입니다.

## 설치

`release/ChzzkMultiView-v1.0.0.apk`를 휴대폰/태블릿에 받아 설치합니다. (출처를 알 수 없는 앱 설치 허용 필요, Android 7.0 이상)

## 기능

- **멀티뷰**: 최대 9개 방송 동시 재생. 화면 크기와 방송 수에 맞춰 16:9 영상이 가장 크게 보이도록 격자를 자동 계산합니다.
- **채널별 볼륨**: 방송마다 독립된 플레이어를 사용하므로 슬라이더로 개별 볼륨 조절, 개별 음소거가 됩니다.
- **솔로 듣기**: 방송을 길게 누르면 그 방송만 소리가 나고 나머지는 음소거됩니다.
- **채팅 on/off**: 각 방송의 💬 버튼으로 해당 채팅창을 켜고 끕니다. 여러 채팅을 동시에 켜면 패널에 세로로 쌓입니다. 상단 💬 버튼은 채팅 패널 전체를 잠시 숨깁니다. 채팅창에서 네이버 로그인하면 채팅 입력도 가능합니다.
- **크게 보기(⛶)**: 한 방송을 메인으로 키우고 나머지를 옆(가로)·아래(세로)에 작게 배치합니다.
- **화질 자동 조절**: 타일 크기에 맞춰 480p/720p/원본으로 화질 상한을 바꿔 데이터와 디코더 부담을 줄입니다. 하드웨어 디코더가 부족하면 소프트웨어 디코더로 자동 전환합니다.
- **자동 재연결**: 오프라인 채널은 1분마다 확인해 방송이 시작되면 자동 재생하고, 끊기면 다시 연결합니다.
- **채널 추가**: 인기 라이브 목록, 스트리머 이름 검색, 채널 URL/ID 붙여넣기, 치지직 앱의 "공유 → 치지직 멀티뷰" 모두 지원합니다.
- 회전해도 재생이 끊기지 않으며, 구성(채널·볼륨·채팅 상태)은 앱을 다시 열어도 유지됩니다.

## 사용법

| 동작 | 결과 |
| --- | --- |
| ＋ | 방송 추가 |
| 방송 탭 | 컨트롤 표시/숨김 |
| 방송 길게 누르기 | 이 방송만 듣기 |
| 🔊 / 슬라이더 | 음소거 / 볼륨 |
| 💬 (방송) | 그 방송 채팅 켜기/끄기 |
| ⛶ | 크게 보기 |
| ✕ | 방송 제거 |
| 💬 (상단) | 채팅 패널 전체 숨기기 |
| 🔊 (상단) | 전체 음소거 |

## 구조

| 파일 | 역할 |
| --- | --- |
| `ChzzkApi.kt` | 치지직 공개 API (검색, 인기 라이브, live-detail → HLS 주소) |
| `StreamTile.kt` | 방송 1개 = Media3 ExoPlayer 1개, 볼륨·화질 상한·재연결 |
| `MultiGridLayout.kt` | 격자/포커스 배치 계산 |
| `ChatPanel.kt` | 치지직 웹 채팅(`/live/{id}/chat`) WebView 관리 |
| `AddChannelDialog.kt` | 채널 검색/추가 |
| `MainActivity.kt` | 화면 구성, 상태 저장 |

## 빌드

```bash
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

JDK 17 이상, Android SDK 35가 필요합니다.

## 알아둘 점

- 연령 제한 방송은 로그인 인증이 필요해 앱 플레이어로는 재생되지 않습니다.
- 비공식 앱이며 치지직 웹 API 변경 시 동작이 달라질 수 있습니다.
- 동시 재생 가능한 개수는 기기 성능과 네트워크에 따라 다릅니다.
